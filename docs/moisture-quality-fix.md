# 실제 기록 기반 1회 접촉 측정 품질 수정

## 무엇을 고쳤나
사용자가 제공한 로그의 공기 기준507/접촉504→503→502 구간을 회귀 자료로 사용했다. 기존 방식은 평균 용량 반응1.241%에 대해 처음/끝 차이0.361%p를 허용했다. 비율로는29%이지만 출력이 1 count 단위이므로 그 비율만으로 실제 불안정을 단정할 수 없다. 임상적인 정확도 개선을 입증한 자료는 아니다.

1. 새 측정의 드리프트 검사는 고정1%p 상한과 함께 신호 크기의15%, 관측 구간의1-count에 해당하는 변화폭을 사용한다. 허용치=min(1%p,max(1-count 변화폭,abs(평균 용량 반응)*0.15)). 작은 반응에 과도한 변화를 허용하지 않으면서 출력 반올림만으로 무조건 실패시키지 않기 위한 초기 공학 기준이다.
2. 드리프트 검사를 통과하지 못하면 같은 접촉을 유지한 채 최신3초 구간을 다시 검사한다. 결과를 여러 번 저장하지 않는다. 접촉 확인부터 총10초 한계는 유지한다. 경고/큰 변동/접촉 해제/수신 중단은 기존처럼 취소한다. 분리 접촉3회를 요구하지 않는다.
3. 공기 기준과 접촉 중앙값에 각각 +/-0.5 count를 적용해 출력 반올림에 의한 표시값 범위를 계산한다. 이 범위는 정수화 영향만의 민감도 계산이며 피부 수분 정확도 범위, 압력 오차 범위, 통계적 신뢰구간이 아니다. 공기 평균을 내도 최악의 정수화 편향을 1/sqrt(N)로 줄었다고 가정하지 않는다.
4. 반올림만으로 대표 반응값의20%를 초과하는 차이가 가능한 결과는 resolution_limited로 저장한다. 결과는 보여주되 추천 보조 입력에서는 제외한다. 이20%는 측정 품질에 관한 초기 공학 설정이고 피부 수분 부족의 경계값이 아니다. 신호가 작다고 피부가 건조하다는 뜻이 아니다. 더 세게 눌러 통과시키라고 안내하지 않는다.
5. 새 결과는 소수1자리로 표시하고 계산 상세에 반올림 영향 범위를 표시한다. 기존1.18%는 같은 값이라도1.2%처럼 표시한다. 임의 배율을 넣어 높은 숫자로 만들지 않는다. 기존 백분율의 물리적 정의는 그대로다.
6. 완료한 결과를 고정한 채 최대30초 동안 후속 진단 표본만 기록한다. 측정은 다시 시작하지 않고 완료 콜백도 재실행하지 않는다. 이후에는 표본 기록을 중단해 보정/완료 구간이 장시간 수신으로 밀려나지 않도록 한다. 화면을 닫거나 연결을 끊으면 수신할 수 없다. 새 파일명 skin-moisture-audit.json, site skin.
7. 서버도 새 드리프트 검사와 정밀도 판정을 수행하고 추천에 사용할 수 없는 결과는 보류한다. 기존 v3 결과의 식/판정은 소급 변경하지 않는다. 이를 위해 내부 algorithm_version만 skin-auto-v4로 구분한다. DB 마이그레이션은 없다.

## 검증
- 제공된 실제 로그를 재생하면 이전 완료 시점에서 아직 collecting으로 유지된다.
- 그 뒤 마지막 count가 유지되는 가상 표본을 추가한 테스트에서는 동일한 접촉 안에서 한 번만 완료한다. 이는 추가 실측 결과가 아니라 알고리즘 동작 테스트다.
- 일정한 약한 신호는 분해능 제한 표시. 충분히 큰 모의 신호는 기존 추천 보조 경로로 연결.
- 서버42개 테스트(기존 수분/추천 및 새 품질 판정), 자동 측정 회귀, 기록 보존, React DOM, TypeScript/Vite 빌드 통과.
- 피부 수분 정확도 및 압력 보정은 검증하지 못했다. 본 변경은 정전용량을 검증된 수분 함량으로 바꾸는 보정 모델을 새로 제공하지 않는다.

## 적용
현재 적용한 BOA-single-contact-response 위에 이 ZIP의 frontend/backend/docs를 프로젝트 루트에 덮어쓴다. 프론트와 백엔드를 함께 적용한다. 하드웨어 변경 및 Arduino 재업로드는 없다.

PowerShell 백엔드:
cd C:\Users\USER\Desktop\BOA-git\backend
docker compose restart api

PowerShell 새 터미널 프론트:
cd C:\Users\USER\Desktop\BOA-git\frontend
npm run dev

코드를 이미지에 포함하는 Docker 설정에서는 restart 대신 docker compose up -d --build api가 필요하다. 브라우저는 새로고침한다.

보정 후 한 번 피부에 접촉한다. 값이 변하면 센서를 떼지 않고 같은 위치/힘을 유지한다. 완료하면 센서를 떼도 결과는 바뀌지 않는다. 새 기록은 완료 후 최대30초까지 진단용 수신을 포함한다. 숫자를 높이려 누르는 힘을 늘리지 않는다.

## 범위
수분 부족/보통/충분의 검증된 기준은 아직 없다. 이 수정으로 그 목표를 달성했다고 주장하지 않는다. 정전용량 반응률을 수동 피부 수분 점수 칸으로 복사하거나 그 값으로 건조 판정하지 않는다.
회귀 fixture는 제공 기록에서 수신 표본을 추출하고 원래 측정ID와 날짜/이벤트 메타데이터를 제거한 것이다. 실제 사진이나 신원 정보는 포함하지 않는다.
