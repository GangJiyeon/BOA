# 1회 접촉 감지 개선과 표시·추천 연결 시험판

이 변경은 절대 피부 수분 정확도나 임상 분류를 완성한 패치가 아니다. 가벼운 접촉을 놓치던 고정 문턱을 개선하고, 임의의 30-count 표시 배율을 제거하며, 화면과 서버 및 추천에서 일치하는 측정값을 사용하도록 수정한 시험 적용본이다. 실제 장치 정확도 개선량은 미확인이다.

## 기존 코드에서 확인한 문제
- 접촉 감지는 원시값 최소2% 감소를 요구했다. 기준506에서는 약10 counts가 필요했다. 반면 과거30-count 표시 지수10에 해당하는 약3-count 감소는 감지 문턱보다 작았다. 즉 가벼운 접촉이 화면에서 보이더라도 자동 측정은 시작하지 않는 모순이 있었다.
- 이 모순은 강한 압력의 전체 원인을 증명하는 것은 아니다. 접촉 면적/간격/압력의 물리적 영향은 남아 있다.

## 수정한 측정 과정
장비/펌웨어 전송 포맷 유지. 공기 보정 → 공기 잡음2초 확인 → 1회 접촉 → 첫 안정 구간 → 3초 수집 → 완료 후 정지. 분리 접촉3회는 요구하지 않는다.
감지 문턱 = max(2 counts에 해당하는 감소율, 공기 평균 편차의 절댓값 + 6×표준편차 + 1 count에 해당하는 감소율).
위 값은 수분 판정 기준이 아니라 감지용 공학 설정이다. 잡음이 크면 문턱도 높아지며, 약한 신호를 무조건 수분 측정으로 확정하지 않는다. 1-count 분해능 이하를 보간해 실제 해상도처럼 주장하지 않는다.
공기 표본을 완료 자료에 함께 보존하고 서버가 문턱을 재계산한다. 피부 구간 표본 경고/순번/시간/변동/드리프트 검사와 출력 경계 거부를 유지한다. 낮은 문턱에서는 피부 이외의 접근/접촉도 감지될 수 있다. 피부 여부나 적절한 접촉 압력을 인증하는 기능이 아니다.

## 숫자의 정의
현재 고정된 gain16/offset170/FIN2 설정에서 f(x)=2*fREF*(x+170)/65536, C(x)=1/(4*pi*pi*L*f(x)^2).
표본별 표시 응답 R(x)=100*(C(x)-C(air))/C(x) = 100*[1-((x+170)/(B+170))^2].
대표값은 3초 유효 표본 R의 중앙값. 시간 전체에서 가장 높은 구간을 골라 쓰지 않는다. 같은 회로에서 L과 기준 클록이 일정하다는 조건에 비율에서 해당 계수가 약분된다. 이는 이상적 LC 모델에서의 등가 정전용량 기여율이며 손실 성분 등의 모델 오차는 남는다.
정상적인 양의 접촉 응답이면 0~100 범위지만, 실제 피부 속 물의 백분율/건조도/Corneometer AU가 아니다. 예: 기준500/접촉497은 약0.89%, 기준500/접촉400은 약27.62%. 작은 값도 곧 건조를 뜻하지 않는다. 이전40%와 직접 비교할 수 없다. 목표 숫자를 만들기 위해 세게 누르지 않는다.
30 counts와 보정되지 않은 임상 장비 계수는 새 계산에 사용하지 않는다. 이전 v1/v2 자료의 계산 의미는 유지하고 새 자료만 skin-auto-v3 / skin-contact-fraction-v1로 구분한다.
측정 부위는 새 자료에서 skin(미지정 피부)로 기록한다. 부위가 달라도 같은 기준을 적용할 수 있다고 검증한 것은 아니다. 비교할 때 같은 부위와 접촉 방법을 유지해야 한다.

## 추천 연결
완료 표본을 분석 ID 및 측정 ID에 묶어 저장한다. 서버에서 원시값으로 다시 계산하고, 저장된 값으로 추천을 조회한다. 페이지를 이동하거나 먼저 측정한 뒤 사진을 분석해도 같은 완료값을 전달한다.
기존 조건이 같은 후보 중 보습 성분 함유를 우선하는 실험적 보조 정책은 유지한다. 보조값0.25*(1-R/100)은 임상적 효과나 건조 정도가 아닌 제품 내 우선순위를 위한 휴리스틱이다. 이 정책의 개인화 효능은 검증되지 않았다. 후보들이 모두 보습 성분을 갖고 있으면 결과 순서가 달라지지 않는다. 별도 수분 점수가 있으면 중복 반영하지 않는다.
R을 임의 경계로 자르거나 수동 수분 점수 입력칸에 복사하지 않는다. 수분 부족/보통/충분 분류와 검증된 정식 수분 점수 대체 목표는 미완료다.

## 적용
v10 또는 v10.1 또는 v11까지 적용된 BOA 프로젝트 루트에 frontend/backend/docs를 덮어쓴다. npm run dev 개발 서버에서는 새로고침. backend에서 docker compose restart api 실행. 이미지에 코드를 포함해 구동하는 환경은 docker compose up -d --build api 실행.
하드웨어 파일은 바꾸지 않으므로 이번 변경만을 위한 아두이노 재업로드는 필요 없다. 기존 gain16/offset170/FIN2 설정의 실제 센서 펌웨어를 전제로 한다.
DB 마이그레이션 없음. 새 알고리즘을 받으려면 프론트와 백엔드를 함께 적용해야 한다.
화면에서 공기 보정 후 피부에 한 번 접촉해 완료 결과와 전체 측정 기록을 확인한다. 실제 장치 결과 없이 이 변경이 피부 수분 정확도를 높였다고 결론 내리지 않는다.

## 검증
- 자동측정: 기준500→497의 작은 신호 완료, 공기 잡음에 따른 감지 문턱 상승, 중복/수신 간격/경고/불안정/재시작 회귀.
- 서버: 공기 자료 누락/잘못된 문턱/출력 경계 거부. 실제 API 저장→재조회→추천 재계산. 기존 v1/v2 경로 유지.
- React DOM: 1회 완료, 완료값 고정, 명시적 재측정, 화면 복귀, 사진 분석 연결, 추천 재조회.
- TypeScript 및 Vite 빌드.
- 피부에서의 정확도/압력 보정/피부 수분 분류 검증은 수행하지 않음.
