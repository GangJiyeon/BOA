# 성분 근거 재검토와 함량 데이터 발견

검토일: 2026-10-05 KST. 대상: 현재 BOA, 규칙 v1 + quality-v1 적용 코드.
1학기 프로젝트는 이번 규칙의 근거로 사용하지 않는다.

## 이번 작업에서 확정한 것

- 기존 활성/보류 설명에 일관성 문제가 있다. '농도 미확인'만으로 일부만 보류하는 기준은 부족하다.
- 연구에서 관찰한 결과, BOA 지표로 연결하는 추론, 특정 제품의 효과를 분리해야 한다.
- 성분을 더 많이 활성화하는 것만으로 현재의 큰 동점 집합 문제가 해결되지는 않는다.
- 수집 SQLite에는 일부 함량 원문이 있다. 현재 PostgreSQL 모델/가져오기/추천 경로가 이 정보를
  구조화된 함량 필드로 전달하지 않는다. '모든 함량 정보가 없다'는 설명은 정정한다.
- 현재 시드 JSON, 엔진, 사용자 DB는 이번 작업에서 수정하지 않았다. 아래 판정은 재검토 결론과
  후속 버전 제안이며 배포 완료/전문가 승인/임상 검증을 뜻하지 않는다.

## 1. 공통 기준

| 구분 | 무엇을 기록하는가 | 점수와의 관계 |
|---|---|---|
| 성분 기능 | 성분 자체의 배합 기능. 공신력 있는 기능 자료가 필요 | 기능 이름만으로 자동 가점하지 않음 |
| 연구 결과 | 대상, 실제 성분, 투여 경로, 제형, 농도, 비교군, 측정 항목, 결과 | 완제품 연구를 단일 성분 효과로 복제하지 않음 |
| BOA 연결 | 수분/홍조/밝기/트러블/균일도 중 어떤 의미에 적용하는지 | 일반 명칭이 아닌 측정 의미와 연결해야 함 |
| 제품 적용 | 함유, 함량 표기, 사용 방식, 부위 등 확인 범위 | 미확인 값을 0, 안전, 적합으로 간주하지 않음 |

'조건부 함유 후보'라는 개발 정책을 유지한다면 글리세린 등 기존 활성 성분도 농도·제형의
불확실성을 공유한다. 특정 성분 하나에만 '농도 미확인'을 적용해 연구 자체가 없는 것처럼
설명하지 않는다. 반대로 실제 제품 효과까지 주장하려면 현재 활성 규칙도 그 수준에 못 미친다.

채택 최소 검토 항목은 명확한 성분 식별, 국소 피부 적용, 지표와 관련된 사람 연구 또는
전문기관 안내, 대조 설계, 결과의 해석 가능성, 제형/대상 차이, 배제 정책과의 충돌이다.
이 기준은 BOA의 설계 기준이며 공식 임상 근거 등급 체계가 아니다.

## 2. 기존 활성 규칙 재검토

| 성분 → 지표 | 확인 내용 | 재검토 결론 |
|---|---|---|
| 글리세린 → 수분 | 20% 제형, 아토피 피부 24명, 기제 대조 연구에서 수분 개선 [1] | 함유 후보 근거는 유지 가능. 일반 얼굴/모든 농도의 효능 확정 아님 |
| 판테놀 → 수분 | 덱스판테놀의 두 기제 대조 연구에서 수분 개선 [2] | 판테놀 이름으로 이성질체·제형을 확정할 수 없음. 조건부 후보라는 점을 유지 |
| 하이알루로닉애씨드 → 수분 | 0.1% HA, 76명 눈가, 기제 대조 수분 개선 [3] | 후보 근거는 있으나 분자량·사용 부위 한계. 염/분해물 자동 확장 안 함 |
| 나이아신아마이드 → 밝기·균일도 | 얼굴 색소침착·피부 밝기 연구 [4] | 사진 조명이나 피부 표면 요철까지 같은 효능으로 묶지 않음. 두 지표는 독립 근거가 아님 |
| 살리실릭애씨드 → 트러블 | AAD 안내는 여드름·모공 막힘과 다양한 농도/제형을 다룸 [5] | 비특이적인 '트러블' 전체에 대한 근거는 아님. 활성 상태를 임상 확정으로 취급하지 않고 범위 제한 필요 |
| 홍조 배제 8종 | 주사 피부 관리 안내의 일부 회피 성분 [6] | 모든 홍조의 질환 판정이나 안전 필터가 아님. 제품 종류·각질 관리 지침까지 모두 구현한 것은 아님 |

특히 살리실산 안내와 홍조 배제 안내의 적용 대상은 서로 다르다.
같은 사용자에게 두 고민이 있다고 해서 각각의 지침을 기계적으로 합치면 적합한 치료가
되는 것이 아니다. 원문에 없는 '모든 산 금지' 같은 규칙을 이번에 추가하지 않았다.

## 3. 보류/확장 후보 재검토

| 성분·대상 | 자료 확인 결과 | 결정과 남은 조건 |
|---|---|---|
| 우레아·수분 | 20명 전완, 5% 단독/복합 제형과 기제 비교, 수분 개선 [7] | 근거 부족 성분으로 취급하면 안 됨. 기존 수분 성분과 같은 '조건부 함유 후보' 기준에서는 확장 검토 가능. 농도 미확인만을 이유로 한 기존 보류 설명은 수정 필요. 실제 활성화는 새 버전에서 |
| 소듐하이알루로네이트·수분 | 15명, 특정 리포좀/젤 제형을 상용 제품과 비교한 연구 [8] | 관련 자료는 찾았지만 제형과 단일 성분 효과를 분리하기 어려움. 이번 자료만으로 일반 제품 모두에 활성화하지 않음 |
| 세라마이드엔피·수분 | 27명, 스테로이드로 손상시킨 전완 장벽에 세라마이드NP 풍부한 지질 혼합물 비교 [9] | 일반 얼굴의 단일 NP 효과로 환산하지 않음. 보류 유지 제안. 원문 페이지에 정정 논문 연결도 있어 내용 확인 전 채택하지 않음 |
| 알란토인·홍조/수분 | 6% 알란토인, 수포성 표피박리증 상처 169명 시험에서 주 평가변수의 기제 대비 우월성 미확인 [10] | 이 시험은 일반 피부 홍조/수분을 평가한 것이 아님. 가점 근거로 채택하지 않음. 이 결과로 모든 용도의 무효를 선언하지도 않음 |
| 판테놀·홍조 | 5% 덱스판테놀과 유발 자극 연구, 유의한 군 차이는 수분 측정에서 확인 [11] | 일반 얼굴 홍조 가점 보류 유지 |
| 나이아신아마이드·트러블 | 4% 젤 대 클린다마이신 활성대조, 76명 [12] | 두 군의 유의차 없음은 동등성 입증이 아님. 비특이적 트러블로의 확대 보류 유지 |
| 병풀추출물·홍조 | HA·글리세린·병풀 유래 배양 성분 복합 제품의 20명 수분 연구 [13] | 이번에 본문 방법/결과/한계/이해상충까지 확인. 단독 추출물도 홍조 시험도 아니므로 보류 유지 |

이번 검토는 체계적 문헌고찰이 아니다. 확인한 자료에서 채택 근거가 부족하다는 뜻이지,
해당 성분의 관련 연구가 세상에 없다는 뜻은 아니다. 베타인 등 다른 후보는 이번에 판정을 완료하지 않았다.

## 4. 실제 데이터에서 활성화만 가정한 결과

원본 DB와 시드는 바꾸지 않고 메모리에서 기존 보류 규칙의 status만 active로 바꿔 계산했다.
이는 근거 승인이 아닌 영향 분석이며, 의료적 안전성/추천 품질의 개선을 뜻하지 않는다.

| 수분 규칙 가정 | 수분만 고민 후보 | 다섯 고민 후보(홍조 필터 켬) | 다섯 고민 후보(홍조 필터 끔) |
|---|---:|---:|---:|
| 현재 | 1,648 | 1,099 | 1,679 |
| 우레아만 추가 | 1,648 | 1,099 | 1,679 |
| 소듐하이알루로네이트만 추가 | 1,665 | 1,106 | 1,689 |
| 세라마이드엔피만 추가 | 1,653 | 1,101 | 1,682 |
| 위 세 개 모두 추가 | 1,669 | 1,107 | 1,691 |

수분만 고민일 때는 세 성분을 모두 추가해도 기존보다 21개만 늘고 상위 5개 제품 ID는 그대로다.
기존 후보에 이미 다른 수분 매칭 성분이 들어 있고 지표별 최대 1점이기 때문이다.
소듐하이알루로네이트를 추가하면 다섯 고민 사례에서 일부 제품의 수분 점수가 새로 붙어
상위 5개 구성은 바뀐다. 따라서 후보 수만 같다고 영향이 전혀 없다고 판단하지 않는다.

## 5. 실제 함량 원문: 없어진 것이 아니라 엔진이 읽지 않는 정보

첨부 SQLite의 `formula_ingredients`에는 `amount_text`, `raw_token`, `position`이 있다.
`primary_formulas`로 대표 처방만 연결해 읽은 결과:

- 전체 제품 2,584개 중 776개에 한 개 이상의 비어 있지 않은 함량 문자열이 있음.
- 대표 처방 행은 76,990개, 고유 제품-성분 연결은 76,970개. 반복 20행을 구별해야 함.
- 비어 있지 않은 함량 문자열 2,587행/2,587개 고유 연결.
- 같은 대표 제품-성분의 서로 다른 비어 있지 않은 함량 문자열 충돌은 이번 집계에서 0건.
- 원본 SHA-256: `7096c10e71cde631c9083e8eb351fcb75cd700c542fef23a716e6b7adabb0216`.

| 성분 | 연결 제품 | 함량 문자열 있는 제품 |
|---|---:|---:|
| 글리세린 | 1,771 | 3 |
| 판테놀 | 995 | 73 |
| 하이알루로닉애씨드 | 525 | 52 |
| 나이아신아마이드 | 1,039 | 70 |
| 살리실릭애씨드 | 108 | 9 |
| 우레아 | 47 | 2 |
| 소듐하이알루로네이트 | 1,141 | 96 |
| 세라마이드엔피 | 636 | 20 |
| 알란토인 | 635 | 3 |

예: A000000117997의 살리실릭애씨드 `100 ppm`, A000000147109의 우레아 `5%`.
이는 수집/파싱된 표기이며 제조사 원문을 현재 다시 검증한 농도가 아니다.
`100 ppm`을 수학적으로 백분율로 바꾸는 것과, 실제 완제품의 질량비 농도를 확정하는 것은 다르다.
복합 원료의 함량일 가능성, 단위 기준, 적용 대상, 표기 오류를 확인해야 한다.

현재 코드에서 확인한 전달 경로:

- `scripts/import_cosmetics.py`는 대표 연결을 그룹화하고 위치를 MIN으로 가져온다. amount_text는 가져오지 않는다.
- `ProductIngredient` 모델에는 product_id/ingredient_id/position만 있다.
- 제품의 `ingredients_raw`에는 원문이 남을 수 있지만 추천 엔진은 이를 함량으로 해석하지 않는다.
- 사용자의 현재 PostgreSQL 열을 직접 조회한 것은 아니다. 위 설명은 읽은 코드와 첨부 SQLite 기준이다.

읽기 전용 재현 도구: `backend/scripts/audit_cosmetic_amounts.py`. 표준 라이브러리만 사용한다.

```sh
python scripts/audit_cosmetic_amounts.py /path/to/beauty_catalog.db
```

## 6. 다음 구현 범위 제안

성분 태그 추가보다 함량 표기의 출처 보존을 먼저 진행한다. 수집을 처음부터 다시 할 필요는 없다.

1. 기존 제품/성분 연결을 덮어쓰지 않는 보조 관측 테이블을 추가하는 설계를 준비한다.
   제품·성분 FK, 원본 처방 ID/위치, raw_token, amount_text, source_hash, 검토 상태를 보존한다.
2. 숫자 함량과 단위/기준은 검증할 수 있을 때만 별도로 기록한다. 누락은 unknown이지 0이 아니다.
3. 원본 상품 ID와 PostgreSQL ID는 같다고 가정하지 않는다. 검증된 원본 URL 등으로 대응시키고,
   중복·누락 시 중단하는 dry-run부터 제공한다. 기존 제품 재이관을 실행하지 않는다.
4. 연구 조건 대비 제품의 적용 가능성을 명시한 규칙 v2를 설계한다.
   함량이 없다고 전체 카탈로그를 없애거나, 알려진 함량에만 임의의 효능 가중치를 붙이지 않는다.
5. 우레아 등의 조건부 후보 확대와 밝기/균일도 중복 근거 표현을 새 버전으로 검수한다.

이 재검토 시점에는 테이블·이관·새 규칙을 구현/적용하지 않았다. 이후 원문 보존 기능을 구현했으며
[원문 이관 절차](cosmetic-observation-import.md)에 신규 스키마와 사전 검사 방법을 기록했다.
새 추천 규칙과 사용자 DB 적용은 여전히 별도 단계다. DB를 바꾸기 전에 변경 이유와
쓰기 대상, 되돌리기 방식, 예상 건수를 따로 안내해야 한다. 지금 사용자가 실행할 DB 명령은 없다.
