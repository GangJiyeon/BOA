# 성분 규칙표 및 DB 설계 v1

규칙 버전: `cosmetic-rules-2026-10-05-v1`. 검토일: 2026-10-05 (KST).

이 문서는 현재 시드 JSON의 20개 규칙을 설명한다. `active`는 개발용 후보 매칭에 사용하는 프로젝트 상태이며 전문가 승인·임상 검증을 뜻하지 않는다. 자료 검토 및 초안 작성은 AI 보조로 수행했다. 원논문의 초록과 안내를 확인한 범위는 아래에 기록하며 전문을 읽지 않은 자료는 전문 확인으로 표시하지 않는다.

## 결정 원칙

- 측정 점수·판정 구간은 기존 임시 기준 유지. 수분·밝기·균일도 0–33, 홍조·트러블 67–100만 개선 필요. 중간 34–66에는 개선 가점을 만들지 않는다. 입력값은 0~100 정수, 수분 null은 평가 제외다.
- 활성 매칭 성분이 하나 이상 있어도 지표별 최대 1점. `match_score`를 모든 성분에 걸쳐 합산하지 않는다. 밝기·균일도는 별도 지표지만 같은 근거를 공유한다.
- 배제는 높은 점수로 상쇄되지 않는다. 사용자 직접 배제는 홍조 옵션과 무관하게 적용한다. 자동 홍조 배제는 해당 판정 구간 + 옵션 켜짐일 때만 적용한다.
- 활성 규칙이 없는 지표는 0점 효능 판정 대신 평가 보류로 표시한다. 점수는 함유 매칭 개수이며 개선 확률이 아니다.
- 농도·pH·분자량·이성질체·완제품 사용법·개인 반응을 데이터가 없는 상태에서 추정해 채우지 않는다. 저농도보다 고농도가 좋다는 점수를 만들지 않는다.
- 모든 규칙은 현재의 leave_on_candidate 범위에만 사용한다. 워시오프 및 사용 방식 불명확 필터는 v2 정책을 유지한다.
- 전체 3,099개 성분을 강제로 분류하지 않는다. 미등록은 미검토이며 무효·안전·위험의 판정이 아니다.

## 근거별 확인 범위와 한계

### glycerol-18025807

[Glycerol emollient versus vehicle in atopic dermatitis](https://pubmed.ncbi.nlm.nih.gov/18025807/)

- 확인 범위: PubMed 논문 초록 확인; 전문 미확인
- 확인 내용: 24명, 20% 글리세롤 제형, 4주 연구에서 수분 지표 개선. 홍반의 군간 차이는 유의하지 않았다.
- 적용 한계: 아토피 피부·특정 농도 연구다. 일반 얼굴 및 수집 제품의 효과를 확정할 수 없다.

### panthenol-10965426

[Topical dexpanthenol: barrier function and hydration](https://pubmed.ncbi.nlm.nih.gov/10965426/)

- 확인 범위: 논문 초록 확인 (Europe PMC MED 레코드); 전문 미확인
- 확인 내용: 두 지용성 기제의 덱스판테놀을 7일 적용한 대조 연구에서 수분 개선과 수분 손실 감소.
- 적용 한계: 판테놀 표기만으로 이성질체·농도·기제를 확인할 수 없다.

### niacinamide-12100180

[Niacinamide: pigmentation and melanosome transfer](https://pubmed.ncbi.nlm.nih.gov/12100180/)

- 확인 범위: 논문 초록 확인 (Europe PMC MED 레코드); 전문 미확인
- 확인 내용: 5% 보습제 및 2%+자외선차단 제형을 사용한 임상 연구에서 색소침착과 피부 밝기를 평가했다.
- 적용 한계: 사진 밝기는 조명에 영향받고 균일도는 색소 외 요인도 포함한다. 두 지표 연결은 프로젝트 추론이며 동일 근거를 공유한다.

### salicylic-aad

[AAD: Acne diagnosis and treatment](https://www.aad.org/public/diseases/acne/derm-treat/treat)

- 확인 범위: AAD 안내 본문 확인
- 확인 내용: 살리실산을 모공 막힘·각질 관리에 사용하는 여드름 치료 안내.
- 적용 한계: 일반 트러블 점수는 여드름 진단이 아니다. 제품 농도·산도·허가사항과 효과는 미확인.

### ha-22052267

[Topical hyaluronic acid formulations of different molecular weights](https://pubmed.ncbi.nlm.nih.gov/22052267/)

- 확인 범위: 논문 초록 확인 (Europe PMC MED 레코드); 전문 미확인
- 확인 내용: 76명 여성의 눈가에 0.1% HA 제형과 기제를 비교한 연구에서 수분 지표 개선.
- 적용 한계: 분자량·농도·부위가 특정되어 있다. 모든 유도체와 염을 자동으로 같은 성분으로 취급하지 않는다.

### redness-aad

[AAD: 7 rosacea skin care tips](https://www.aad.org/public/diseases/rosacea/triggers/tips)

- 확인 범위: AAD 안내 본문 확인
- 확인 내용: 주사 피부 관리 안내의 회피 성분 목록을 참고했다.
- 적용 한계: 높은 홍조 점수로 주사를 진단하지 않는다. 선택 가능한 프로젝트 보수 정책이며 안내 전체를 구현한 것도, 알레르기 안전 판정도 아니다.

### panthenol-14641355

[Dexpanthenol protection against experimentally induced irritation](https://pubmed.ncbi.nlm.nih.gov/14641355/)

- 확인 범위: 논문 초록 확인 (Europe PMC MED 레코드); 전문 미확인
- 확인 내용: 건강한 전완에 SLS로 자극을 유발한 연구. 통계적 군간 차이는 corneometry에서만 보고됐다.
- 적용 한계: 일반 얼굴 홍조 개선 가점으로 바로 적용할 근거가 부족하다.

### nicotinamide-7657446

[4% nicotinamide versus 1% clindamycin for inflammatory acne](https://pubmed.ncbi.nlm.nih.gov/7657446/)

- 확인 범위: 논문 초록 확인 (Europe PMC MED 레코드); 전문 미확인
- 확인 내용: 76명, 8주 활성대조 연구에서 두 군의 여드름 지표 개선을 보고했다.
- 적용 한계: 활성대조 시험의 유의차 없음은 동등성 증명이 아니다. 비특이적 트러블 점수와 제품 함량에 대한 적용 검토를 보류한다.

### urea-11803256

[Urea/ammonium lactate: skin protection and hydration](https://pubmed.ncbi.nlm.nih.gov/11803256/)

- 확인 범위: 논문 초록 확인 (Europe PMC MED 레코드); 전문 미확인
- 확인 내용: 20명의 전완, 2주 연구에서 5% 우레아와 복합 제형의 수분 개선 보고.
- 적용 한계: 농도와 제형에 따라 해석이 달라지므로 농도 미확인 제품의 수분 가점은 이번 버전에서 보류한다.

### ceramide-32372387

[Ceramide-based versus urea moisturizer: pediatric AD irritation](https://pmc.ncbi.nlm.nih.gov/articles/PMC7367988/)

- 확인 범위: PMC 전문 확인
- 확인 내용: 소아 아토피 피부에서 두 완제품의 즉각 자극 정도를 비교한 연구.
- 적용 한계: 완제품 복합 지질 제형 비교이며 세라마이드엔피 단일 성분의 수분 효과를 분리하지 않는다. 제조사 연구비 지원.

### centella-combination

[HA/glycerin/Centella combination: 24-hour hydration](https://pmc.ncbi.nlm.nih.gov/articles/PMC5560567/)

- 확인 범위: 논문 검색 색인 요약만 확인; 본문 접근 차단
- 확인 내용: HA·글리세린·병풀 유래 성분의 복합 제형 수분 연구가 검색됐다.
- 적용 한계: 병풀추출물 단독·얼굴 홍조 효능 근거로 채택하지 않는다.

## 보류·누락을 다루는 기준

하이알루로닉애씨드 수분 매칭을 추가했지만 소듐하이알루로네이트·가수분해물까지 같은 태그로 복제하지 않았다. 특정 연구의 염·분자량 대응이 확인되면 별도 규칙으로 검토한다. 병풀추출물은 이번에 확인된 복합 수분 제형 연구만으로 홍조 가점을 만들지 않는다. 알란토인은 이번 규칙집에서 근거 검토를 완료하지 않아 등록하지 않았다.

배제 목록은 AAD 안내 중 DB 표기가 확인된 8개다. 안내의 sodium lauryl sulfate에 해당하는 정확한 `소듐라우릴설페이트`는 첨부 성분 목록에서 찾지 못해 DB 규칙을 만들지 않았다. 비슷한 이름의 라우릴/라우레스/암모늄 성분을 임의로 대체하지 않는다. 향료 태그 하나가 모든 향 성분을 포괄하지 않으며 에탄올·변성알코올 정책은 지방알코올 전체 배제가 아니다. AAD의 모든 생활/제품 지침을 구현한 주사 전용 추천기가 아니다.

우레아는 수분 관련 연구가 있으나 농도 조건 검토가 필요해 매칭은 보류하고, 홍조 옵션의 배제만 활성화했다. 이는 보편적인 유해 성분 분류가 아니다. 나이아신아마이드 트러블 매칭도 특정 여드름 연구를 모든 트러블에 확대하는 판단을 보류했다. 반면 살리실릭애씨드는 기존의 전문기관 안내 기반 후보 규칙을 유지하되 그 한계를 사유에 표시한다. 이 선택은 프로젝트 정책으로서 추가 검토 대상이며 치료 효능의 우열 판정이 아니다.

| 새 테이블 | 역할 |
|---|---|
| cosmetic_rule_sets | 버전·설명·규칙 내용 해시 |
| cosmetic_rule_evidence | 버전별 근거 코드·출처·검토 범위·요약·한계·검토일 |
| category_ingredients | 판정 구간 FK·성분 FK·규칙 코드·역할·상태·배제 옵션·사용 방식·근거 FK·판단 이유 |

규칙의 기본키는 `(rule_version, code)`다. `(rule_version, category_id, ingredient_id, effect)`도 유일해야 한다. 성분과 판정 구간의 숫자 ID는 PC마다 다를 수 있으므로 시드에서 정확한 성분명 및 지표 코드/구간명으로 FK를 찾는다. 같은 정규화 이름이 중복되거나 필수 성분이 없으면 추측하지 않고 중단한다.

이 버전은 규칙별 대표 근거 1개를 연결한다. 여러 연구를 한 규칙에 독립적으로 연결해야 할 때는 규칙-근거 연결 테이블로 확장한다. 추천 이력 저장은 이번 작업에 포함하지 않는다.

## 버전 및 변경 운영

- `backend/app/data/cosmetic_rules_v1.json`이 배포용 시드 원본이다. API는 이 파일을 읽어 대체하지 않고 DB에 설치된 버전을 조회한다.
- 시드는 기본 dry-run이며 --apply일 때만 INSERT한다. 기존 버전과 내용이 같으면 unchanged로 종료한다. 기존 버전의 내용이 다르면 덮어쓰지 않는다.
- API는 버전 해시로 부분 삭제/직접 수정을 감지하며 잘못된 규칙으로 추천하지 않고 503을 반환한다. 상태 변경도 새로운 버전으로 배포한다. 버전 선택은 DEFAULT_RULE_VERSION을 명시적으로 변경한다.
- 향후 임계값만 바꾸면 해당 category_id의 연결을 그대로 사용할 수 있지만, 분석 로직 버전은 별도 관리해야 한다. 이번 규칙 해시는 피부 구간 숫자를 포함하지 않는다. 이름 변경/구간 재구성은 시드와 함께 재검토한다.
- 현재의 표시용 구간명 `개선 필요`에 의존한다. 회의 후 구간 식별 코드가 합의되면 stable code를 추가하는 것이 후속 과제다.

## 적용 순서 (Windows, v2 패치 적용 상태 기준)

추가 마이그레이션 `400e4e798f5c → c0510a1b2c3d`는 새 테이블 3개만 생성한다. 시드는 규칙 20건·근거 11건·버전 1건을 새 테이블에 넣는다. 기존 제품/성분/피부 점수/헤어 데이터 및 수집 SQLite를 갱신하지 않는다. 코드 반영 후 마이그레이션·시드가 끝나기 전에는 추천 API가 503을 반환할 수 있다.

```powershell
cd C:\Users\USER\Desktop\BOA-git
git apply --check "$HOME\Downloads\boa-cosmetic-rules-db-v1.patch"
# 위 검사 성공 시에만 실행
git apply "$HOME\Downloads\boa-cosmetic-rules-db-v1.patch"
cd backend
docker compose exec api alembic upgrade c0510a1b2c3d
docker compose exec api python scripts/seed_cosmetic_rules.py
# dry_run 검사 성공 시에만 저장
docker compose exec api python scripts/seed_cosmetic_rules.py --apply
docker compose exec api python -m unittest discover -s tests -v
```

각 명령에서 오류가 나면 다음 단계로 넘어가지 않고 출력 내용을 확인한다. 현재 패치는 이미 적용한 v2 위에 추가로 적용하는 증분 패치다. 원래 v2 패치를 다시 적용하지 않는다.
