# 센서 신호 → 피부 수분 상태: 판정 기준 검토

이 문서는 추정기 구현 **이전**의 검토 기록이다. 이후 공개 예제 구간을 실험 정책으로 차용한 구현과 한계는 `hydration-estimator.md`에 있다. 아래 divider10 계산은 명목 인자를 사용한 이전 가정이며, 구형 제조사 드라이버의 실제 divider11 동작을 확인한 뒤 새 모델에서는 사용하지 않는다.

검토일: 2026-10-28. 이번 문서는 판정 기준 검토 결과이며, 새 판정기를 배포하거나 현재 판정의 정확도를 인증하지 않는다.

## 확인한 구현 문제

`app/services/moisture_normalization.py`와 프론트엔드는 정전용량 증가율 0–10%를 1–100점으로 늘린다. 10%라는 상한은 피부 기준 측정으로 정한 상한이 아니다. `app/api/routes/moisture.py`는 이 점수를 SkinScore에 저장하면서 기존 DB 점수 구간으로 카테고리를 정한다. 따라서 현재 연결은 ‘생리학적으로 추정한 상태를 점수로 표시’하는 구현이 아니다. 추천 정책 자체가 정상 동작해도 입력된 상태의 정확도까지 확보되는 것은 아니다.

사용자 PC에서 확인한 f0910a1b2c3d 마이그레이션과 35개 규칙 시드는 추천 정책 적용 성공이다. 센서 판정 기준의 검증 성공을 뜻하지 않는다.

## 검토한 기준과 채택 여부

| 후보 | 확인한 내용 | 판정 |
|---|---|---|
| 현재 10% 상한 환산 | 임의 공학적 스케일 | 피부 상태 경계의 근거로 사용 불가 |
| 제조사 상대 수치 | 공기 기준 raw 감소율, 제조사 예제 코드 존재 | 신호 지표로 재현 가능. 자체적으로 부족/보통/충분 경계 제공하지 않음 |
| PNJ 2023 동일 보드 연구 | 부록에 gain16, offset170, divider10 및 상태 구간 존재 | 출처 있는 후보지만 경계값의 정확도 검증은 공개 부록에서 확인되지 않음. 생산용 기준으로 채택하지 않음 |
| JARTEL 2026 얼굴 측정 연구 | 비교 측정과 퍼지 추천 제시 | raw→표시값 변환 및 설정이 부족해 현재 신호에 경계를 이식할 수 없음 |
| JMEDiTEC 2026 동일 보드 비교 연구 | 초록에 Corneometer와 3상태 비교 기재 | 본문 PDF 서버 오류. 변환식·경계값·혼동행렬은 확인하지 못함 |

PNJ 부록의 여섯 구간은 0–12 Very Low, 12 초과–22 Low, 22 초과–27 Low Normal, 27 초과–39 Mid Normal, 39 초과–45 High Normal, 45 초과–100 Very High다. 이를 세 구간으로 합치면 <=22 / >22–45 / >45가 되지만, 이 합침 자체도 BOA의 해석이며 검증된 BOA 기준이 아니다. 특히 39를 정상/높음 경계로 가져오면 원문의 High Normal을 잘못 읽게 된다.

## 설정 차이와 실제 기록 대입

동일 clock, offset170, gain16, 주파수 입력 분주비를 유지하고 출력 손실이 없다는 조건에서, reference divider D의 raw x를 제조사 예제 divider10에 맞추는 식은 다음과 같다.

```
x10 = (x + 170) * 10 / D - 170
B10 = (B + 170) * 10 / D - 170
manufacturer_response = 100 * (B10 - x10) / B10
capacitance_increase = 100 * (((B + 170) / (x + 170))^2 - 1)
```

이 식은 설정 환산이며 피부 교정식이 아니다. 공기값을 빼는 계산의 분모에는 offset이 포함되어 있어 제조사 raw 감소율은 reference divider에 불변하지 않다. 반면 보정된 raw의 비로 구한 정전용량 변화율에서는 같은 설정의 clock/divider가 상쇄된다.

저장된 최초 접촉부터 고정 3초 기록의 마지막 1초 중앙값 x=2506, 공기 B=2540에 대해:

- 정전용량 증가율: 2.557249%.
- 현재 임의 10% 상한 점수: 26점.
- D=44로 가정한 제조사 설정 환산: B10=445.909091, x10=438.181818, 감소율=1.732926%.
- PNJ 부록 구간을 기계적으로 적용하면 Low 계열이지만, 이것이 사용자 피부의 실제 수분 부족을 입증하지 않는다.

BLE 기록에 실제 divider readback이 없으므로 D=44는 해당 펌웨어 선택 방식과 공기값에 따른 가정이다. 이를 확정된 측정 설정으로 저장하거나, 1.73을 실제 피부 수분 함량으로 표시하면 안 된다. 현재 기록에는 피부 수분 상태 정답 라벨이 없어 어느 경계가 정확한지 계산할 수 없다.

## 이번 검토의 결론

현재 코드의 점수는 재현 가능한 센서 반응 환산이지만, 피부 수분 상태 판정 기준은 아니다. 공개 코드에서 찾은 구간도 현재 측정에 대한 검증을 대신하지 못한다. 이번 검토만으로 유효한 부족/보통/충분 판정기를 완성했다고 보고할 수 없다. 이 때문에 새 임의 경계값이나 점수 확대 패치는 적용하지 않았다. 기존 1회 접촉·고정 3초 종료 동작과 추천 정책도 변경하지 않았다.
