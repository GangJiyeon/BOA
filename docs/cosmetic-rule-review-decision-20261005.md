# 성분 규칙 검수 결정과 실제 제품 사례

검토일 2026-10-05. 엔진 v3.3 / 규칙 cosmetic-rules-2026-10-05-v1.

## 판정

현재 규칙은 개발용 성분 함유 후보 탐색으로 재현 가능하지만 실제 피부 분석 점수에 대한 효능 기반 추천으로 확정할 수 없다. 수분 3개 매칭은 조건부 후보로 유지 가능한 근거가 있다. 밝기·균일도·트러블 3개 매칭은 분석 지표의 의미가 연구 평가 대상과 일치해야 한다. 이 조건이 불명확한 실제 분석 연동에서는 해당 가점을 보류하는 것이 이번 검수의 권고다. 더미 입력 시 개발 가정으로 실험하는 것과 구분한다.

이번 산출물은 검수 기준과 재현 도구다. 사용자 DB 규칙을 바꾸거나 활성 상태를 몰래 바꾸지 않았다. 활성 6개라는 기존 상태와 검수 권고를 구별한다.

## 활성 6개 규칙의 판단

| 규칙 | 실제 확인 범위 | 결정 / 적용 조건 |
|---|---|---|
| 글리세린 → 수분 | 아토피 피부 24명, 20% 제형과 기제 비교, 4주 수분 개선. 홍반 군간 차이는 유의하지 않음 [1] | 수분 함유 후보 유지. 일반 얼굴 완제품 효과·붉은기 개선으로 확장하지 않음 |
| 판테놀 → 수분 | PubMed 검색 반환 초록 일부에서 7일 수분 개선·TEWL 감소 확인 [2] | 조건부 후보 유지. 판테놀 표기만으로 덱스판테놀 이성질체·제형·농도를 확정하지 않음 |
| 하이알루로닉애씨드 → 수분 | 여성 76명, 눈가, 0.1% 여러 분자량 제형과 기제 비교, 수분 개선 [3] | 조건부 후보 유지. 다른 염·가수분해물이나 완제품 농도로 자동 확장하지 않음 |
| 나이아신아마이드 → 밝기 | 5% 보습제의 색소침착 대상 18명, 2%+자외선차단 제형 등의 얼굴 태닝 대상 120명이라는 연구 설계 확인 [4] | 색소 관련 고민일 때만 후보 연결을 검토. 낮은 영상 밝기 자체를 개선 필요로 보는 근거로 쓰지 않음 |
| 나이아신아마이드 → 균일도 | 밝기 규칙과 같은 연구 [4] | 색소성 불균일인지 확인 필요. 표면 요철·그림자·붉은 반점 전체에 일반화하지 않음. 별도 독립 효과 두 개로 합산하지 않는 방향 권고 |
| 살리실릭애씨드 → 트러블 | AAD 여드름 안내의 모공 막힘·각질 관리 맥락 [5] | 비특이적인 트러블 점수만으로 임상 효과를 연결하지 않음. 모공 막힘 관련 지표인지 확인 후 적용 범위 확정 |

연구의 농도를 제품에 일괄적인 최소 유효 농도로 적용할 근거를 확보한 것은 아니다. 농도가 미상인 제품은 0점이라는 결론도 도출하지 않는다. 후보 함유 매칭과 완제품 효과 검증을 분리하는 동일 기준을 모든 성분에 적용해야 한다.

우레아는 별도 재검토에서 수분 근거가 확인됐다 [7]. 다른 수분 성분도 함량이 미상인 상황에서 우레아만 '함량 미상'으로 보류하는 설명은 일관성이 없다. 후속 규칙 버전에서는 같은 후보 기준으로 재평가해야 한다. 다만 이번 원본에서 우레아 활성화 가정은 아래 사례들의 후보 수와 Top 5를 바꾸지 않아 우선적인 순위 개선 수단은 아니다. 현재 v1의 내용 해시를 깨는 직접 수정·재시드는 하지 않는다.

## 피부 분석 코드와의 연결 문제

현재 읽은 `app/services/skin_analysis.py`는 해시로 더미 점수를 생성한다. 주석의 추후 계획은 밝기 Lab L 평균, 트러블 색상 threshold+blob, 균일도 톤 표준편차의 역수다. 이는 실제 구현·성능 검증 완료를 뜻하지 않는다. 최근 원격 Kim 브랜치의 구현은 이번에 읽지 않았다.

- 밝기: 개인의 피부색 또는 촬영 밝기가 낮다는 것 자체로 색소성 개선 필요를 판정할 수 없다. 평균 밝기와 관심 있는 색소 변화량을 구분할 계약이 필요하다.
- 균일도: 무엇의 편차인지, 조명·그림자·붉은기·질감 영향이 어떻게 분리되는지 필요하다.
- 트러블: 검출된 색상 영역이 무엇을 나타내는지, 비여드름성 변화가 구별되는지 필요하다.
- 수분: 이번 연구 검수는 센서 점수 구간의 타당성을 검증하지 않는다. 실제 센서 연결에는 캘리브레이션과 점수 방향 검증이 별도로 필요하다.

실제 분석 연동 전 팀에서 확정할 항목은 지표 정의·원시 측정량·점수 방향·정규화 방식·미측정 표시·측정 신뢰도다. 0~100 숫자라는 형식 합의만으로 충분하지 않다.

## 붉은기 배제의 범위

현재 8개 성분 배제는 주사 관리 안내의 일부 목록을 프로젝트 정책으로 옮긴 것이다 [6]. AAD 안내는 SLS, 제품 종류, 각질 관리 등도 다룬다. 지금 코드가 그 안내 전체를 구현하지 않으므로 옵션 통과를 '주사에 적합'이나 '민감 피부 안전'으로 표시하면 안 된다. 토너가 통과할 수 있다는 점도 같은 한계다. 특정 진단 없이 안내 전체를 자동 강제하는 것도 이번 결정에 포함하지 않는다.

붉은기 가점은 계속 보류한다. 이는 관련 연구가 세상에 없다는 뜻이 아니라 현재 검토·채택한 근거가 일반 얼굴 붉은기 가점을 정당화하지 못한다는 뜻이다. 추가 검색에서 발견한 덱스판테놀 PMID 19753737은 이번에 본문·결과를 읽지 못했으므로 새 근거로 채택하지 않았다.

## 현재 정책이 상위 순위에 주는 영향

v3.3 원본 비교에서 다섯 지표 개선 필요 입력의 1위는 A000000117997이었다. 수분 1점, 나이아신아마이드의 밝기·균일도 2점, 살리실산 트러블 1점으로 총 4점이다. 공유 근거와 제품 효과 미확인이 섞인 수치이므로 '4개 효과가 충분함' 또는 효능 확률로 읽으면 안 된다. 임시 ID가 원본 제품 코드 순이므로 사용자 PostgreSQL의 1위라고 주장하지 않는다.

아래 보류 가정은 우레아 후보 활성화와 밝기·균일도·트러블 가점 보류를 함께 적용한 기존 오프라인 비교 방식이다. 두 변화를 구분하기 위해 우레아만 활성화한 경우도 함께 확인했다. 운영 규칙은 바꾸지 않았다.

| 사례 | 현재 후보 | 우레아만 활성화 가정 | 지표 의미 미확정 가점 보류 가정 |
|---|---:|---:|---:|
| 수분 단독 | 1,609 | 1,609 | 1,609 |
| 밝기 단독 | 924 | 924 | 0 |
| 트러블 단독 | 92 | 92 | 0 |
| 복합 고민 | 1,075 | 1,075 | 1,060 |
| 수분 미측정 복합 고민 | 621 | 621 | 0 |

우레아만 활성화한 경우 이 5개 사례의 Top 5 ID와 점수도 같았다. 지표 의미 미확정 가점을 보류하면 복합 고민의 Top 5와 점수가 달라졌다. 후보 수가 크게 줄지 않아도 순위의 의미는 달라진다.

```powershell
cd C:\Users\USER\Desktop\BOA-git\backend

```

현재 기준은 원본 SHA-256 `7096c10e71cde631c9083e8eb351fcb75cd700c542fef23a716e6b7adabb0216`, v1 규칙 해시, 엔진 v3.3에 고정한다. 카탈로그나 엔진이 바뀌면 검사기는 재검토를 요구한다. 이는 검수 도구의 기준 유효성 검사이며 서비스 API 동작을 막지 않는다. 사용자 PostgreSQL에 연결하거나 쓰지 않는다.

다음 구현에서 필요한 결정은 순위 옵션 추가가 아니라 실제 분석 입력에 적용할 의미 계약이다. 팀 합의가 없는 상태로 실제 지표와 현재 가점을 연결하지 않는다. 개발용 더미 실험은 계속할 수 있다. 계약을 확정한 뒤 새 규칙 버전으로 적용 범위를 좁히고, 같은 실제 제품 사례를 이용해 기본 순위를 선택한다.
