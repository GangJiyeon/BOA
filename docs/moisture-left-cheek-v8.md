# BOA 왼쪽 뺨 전용 조사 및 v8 검증 패치

## 결론과 범위
왼쪽 뺨만 측정 대상으로 고정한다. 손가락 기록은 과거 통신 확인 자료이며 피부 모델 보정 데이터로 쓰지 않는다.
현재 제공물은 설정 검증·전체 기록 기능 및 v7.1 전달 오류 수정을 포함한다. 검증된 피부 수분 변환식이나 추천용 판정 모델이 완성된 버전은 아니다. 실제 사용자 장치의 3% 원인은 아직 미확정이다.

## 조사 결과와 출처
1. 제조사 원본 및 SDK2
https://github.com/MikroElektronika/Moisture_click/blob/master/library/__moisture_driver.c
https://github.com/MikroElektronika/mikrosdk_click_v2/tree/master/clicks/moisture
소스를 직접 대조했다. 16회 읽기 평균 후 공기 기준 대비 감소율을 반환한다. 우리 구현과 게인 0x0600, 오프셋 0x00AA, 클록 0x200B 등 초기 설정이 같다. 다만 제조사 원본은 1ms 간격 읽기와 경고 상위비트 제거를 사용한다. BOA는 새 변환만 취합하고 경고를 제외한다. 같은 함수/공식 사용만으로 왼쪽 뺨에서의 임상적 타당성이 증명되지는 않는다.

2. TI FDC2x1x 데이터시트, Gain and Offset 절
https://www.ti.com/lit/gpn/FDC2212
FDC2112는 내부 16비트 결과 중 12비트를 출력하고 게인 설정으로 비트 구간을 바꾼다. 오프셋도 적용된다. 상위비트가 변하는 범위에서 게인을 쓰면 정보 손실이 발생할 수 있다고 안내한다. 출력 count는 피부 수분율 그 자체가 아니다. 설정과 동작 범위를 검증하지 않고 주파수·정전용량·피부 수분으로 역산하면 안 된다. 정전용량 복원에 성공해도 피부 수분량으로 변환하는 검증은 별개다.

3. 동일 센서의 얼굴 피부 연구
Yeli Herlina L, 2023, Rancang Bangun Sistem Kesehatan Kulit Wajah Berbasis Android.
https://repository.pnj.ac.id/id/eprint/14177/
공개 부록: https://repository.pnj.ac.id/14177/2/Halaman%20Identitas%20Skripsi.pdf
16명, Moisture click/ESP32 및 얼굴 측정 사례를 확인했다. 공개 부록에는 왼쪽 뺨 앱 코드가 있다. MCU에서는 여러 구간으로 분류하지만 앱에서는 3·5 경계로 분류한다. 동일 코드 안에서도 분류 척도가 달라 보인다. 본문 2~4장은 접근 제한이며 검증 과정과 왼쪽 뺨 전용 변환식을 충분히 확인하지 못했다. 범용 판정 기준으로 채택하지 않는다. 저장소 제한 파일은 접근하지 않았다. 과거 팀이 이 코드를 사용했다는 증거도 없다.

4. 측정 절차 지침
https://pmc.ncbi.nlm.nih.gov/articles/PMC4522909/
검색으로 확인한 지침은 피부 수분 장비의 보정 확인, 뺨 측정 자세 및 일정한 접촉 압력을 다룬다. 본문 직접 열기는 접근 확인 화면으로 차단되었으므로 검색에 노출된 내용 이상을 근거로 수치 규칙을 만들지 않았다.

5. 다른 피부 장비 간 비교 연구(변환식으로 사용하지 않음)
https://pmc.ncbi.nlm.nih.gov/articles/PMC11439984/
Corneometer는 임의 단위(AU), 비교 장비는 전도도 단위를 사용한다. 이 연구는 팔/정강이 대상이며 BOA 왼쪽 뺨의 판정 기준이 아니다. 장비별 단위와 검증을 구분해야 한다는 참고로만 사용했다.

## 계산과 미확정 원인
현재 상대 지표 = max(0, (공기 기준 - 접촉 평균) / 공기 기준 × 100).
산술 대조는 완료했으나 이 식이 피부 수분 함량을 직접 나타낸다는 근거는 확보하지 못했다. 3%를 정상이라고 판단하지 않았고 20~50에 맞추는 임의 배율도 넣지 않았다.
미확정 후보: 보정 당시 상태, 접촉 면적/힘/방향, 충분한 접촉 전 측정 확정, 설정 불일치, 센서 경고, 서로 다른 코드의 단위/표본 처리. 전체 기록으로 구분하며, 한 원인을 미리 확정하지 않는다.

## 구현한 변경
- hardware/arduino/moisture_sensor/Fdc2112.h: 게인·오프셋·클록·settle count·conversion count를 실제 읽어 CONFIG 로그에 남긴다. 예약 비트/리셋 비트를 제외한 안정된 필드를 검증한다. 불일치/읽기 실패 시 시작 성공으로 처리하지 않는다. 정상 복귀 시 기존 재연결 흐름을 사용한다. 모든 레지스터를 검증한다는 의미는 아니다.
- 같은 폴더 moisture_sensor.ino: moisture-cheek-audit-v8 버전 표기 및 피부/손을 떼는 보정 안내.
- 프론트: 왼쪽 뺨 전용 안내. 보정·수신 표본·경고·자동 상태·완료 이벤트·연결 해제를 JSON으로 내보낸다. 최근 3,000개만 메모리에 보관하며 누락 개수도 표시한다. 약 100ms 수신이면 약 5분이고 이벤트 수에 따라 달라진다. 사진/계정 정보는 수집하지 않는다.
- 완료 결과 JSON과 별도로 전체 기록을 제공해 채택되지 않은 표본도 확인한다. BLE에 설정 필드가 없어 실제 설정은 시리얼 CONFIG 로그로 확인한다. 파일에 확인하지 않은 설정을 실제값처럼 기록하지 않는다.
- v7.1의 첫 사진 선택 시 결과 보존 및 메뉴 이동 중 저장 유지 포함.

## 적용
기존 v7 또는 v7.1 적용 프로젝트에 이 ZIP의 frontend/hardware/docs 폴더를 덮어쓴다.
기존 hardware/arduino/moisture_sensor/moisture_sensor.ino를 열어 UNO R4 WiFi, COM5로 한 번 업로드한다. 새 스케치를 만들지 않는다. 프론트 재시작 후 브라우저 새로고침 및 측정기 재연결. DB 마이그레이션 변경은 없다. v7 서버/DB 설정은 적용되어 있어야 한다.

## 필요한 최소 실제 확인
1. 업로드 후 115200 시리얼 출력의 CONFIG 5줄과 verified 줄을 보관한다.
2. 센서 면이 피부·손에 닿지 않은 상태에서 기준값 보정을 누른다.
3. 같은 왼쪽 뺨 위치에 같은 방향으로 가볍게 접촉한다. 눈 주변을 피한다. 숫자를 올리려고 압력을 늘리지 않는다.
4. 이번 원인 확인에 한해 자동 완료 후에도 같은 접촉을 약 5초 더 유지하고 떼어 준다. 5초는 완료 후 변화를 관찰하기 위한 실험 시간이며 표준 피부 측정 시간이 아니다.
5. 같은 과정을 총 3회 수행하고 '측정 상세 및 연결 확인'에서 '왼쪽 뺨 전체 측정 기록 내려받기'를 한 번 누른다. 메뉴를 이동하거나 새로고침하기 전에 내려받는다. 화면을 떠나면 기록이 사라질 수 있다.
6. JSON 1개와 CONFIG 로그를 전달한다. 측정 실패도 숨기지 말고 그대로 기록한다. 화장품 도포·세안 직후 등 조건이 달랐다면 함께 알려준다.

접촉 힘을 검출하는 부품이 없으므로 일정한 힘을 소프트웨어로 보장할 수 없다. 신호 안정은 접촉 타당성을 보장하지 않는다. 수치로 압력을 지정하려면 기구/기준 장치가 필요하다.

## 피부 모델을 확정하기 위한 다음 단계
전체 기록은 3%의 소프트웨어·신호 원인을 좁히는 데 사용한다. 이것만으로 절대 수분율을 학습하지 않는다. 같은 왼쪽 뺨 위치에서 기준 장비와 짝지은 측정을 하고, 여러 사람·세션의 반복 오차 및 별도 검증 자료를 확보해야 한다. 같은 사람의 반복값을 무작위로 학습/검증에 나눠 성능을 부풀리지 않는다. 모델 단위는 기준 장비 단위로 명시하며 AU를 퍼센트로 바꾸지 않는다. 기준 장비가 없다면 검증된 수분 점수/건조 판정/수분 기반 추천 가중치를 아직 완성할 수 없다고 보고한다.

## 검증
UNO R4 WiFi 실제 타깃 컴파일 성공(프로그램 93,772바이트, 전역 메모리 11,812바이트). 실제 기기에 업로드하지는 못했다.
C++ 호스트 테스트: 설정 불일치 감지, 재초기화 복원, 예약 비트 제외, 새 변환/보정/경고/재연결 통과.
프론트 빌드 및 자동 측정 상태·계산식 회귀 통과. React DOM 테스트에서 첫 사진 연결·저장 중 메뉴 이동·피부분석 결과 전달 통과. 전체 기록은 경고 보존·복사 격리·시간·메모리 상한 테스트 통과.
검증되지 않은 항목: 사용자 장치 설정 실측, 왼쪽 뺨 반복성, 피부용 변환식, 건조 판정, 수분 지표에 근거한 추천.
