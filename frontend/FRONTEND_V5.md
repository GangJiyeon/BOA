# BOA 프런트엔드 v5 — 사진 촬영·미리보기·결과 필터

기준: v4 (`d98742f`). 이 패치는 v4가 적용된 작업 폴더에 추가한다.
변경 파일은 모두 `frontend/`에 있다. 백엔드, DB, API 계약, 추천 규칙과
패키지 의존성은 변경하지 않았다.

## 사진 입력

- 피부 사진은 선택 후 큰 미리보기로 업로드 안내를 대체한다.
  `1장 선택됨`과 별도 작은 썸네일은 피부 화면에서 제거했다.
  헤어의 여러 장 업로드 화면은 유지한다.
- 이미지 비율을 유지하며 프레임을 채운다. 사진 전체 보기, 1~3배 확대,
  드래그·방향키 이동 및 초기화를 제공한다. 얼굴 자동 검출 확대는 아니다.
- 화면의 확대·이동은 원본 File을 수정하지 않는다. 추천을 조회한 뒤
  미리보기만 조절해도 결과가 지워지지 않는다.
- 사진 찍기, 다시 찍기, 사진 변경, 삭제를 지원한다.
  카메라는 브라우저 권한이 필요하며 localhost 또는 HTTPS에서 사용한다.
  접근 거부·카메라 없음·다른 앱 사용 등의 오류를 안내한다.
- 촬영은 JPEG 파일을 만든다. 분석 시작 전에는 전송하지 않는다.
  기존 피부 분석 업로드 API에 같은 형식으로 보낸다.
- 촬영·닫기·취소·카메라 전환·화면 이동·탭 숨김·컴포넌트 종료 때 스트림을
  정리한다. 창을 닫은 뒤 늦게 허용된 카메라도 즉시 종료한다.

## 추천 결과 필터

- 분석 전 제품 종류 선택을 제거했다. 처음에는 `category: null`로
  지원하는 전체 기초 제품(보습제·세럼·토너)을 대상으로 추천한다.
- 추천 결과의 `전체 / 보습제 / 세럼 / 토너` 버튼으로 종류를 선택한다.
  현재 화면의 상위 몇 개만 숨기는 방식이 아니라, 기존 분석 점수와 제외
  조건을 재사용해 추천 API를 다시 호출한다. 사진 분석은 반복하지 않는다.
- 조회 중·실패 시에는 기존 결과와 적용 중인 종류를 유지한다.
  실패하면 다시 조회할 수 있고, 연속 선택 시 마지막 요청만 반영한다.
- 종류 변경 시 페이지 정보는 초기화하고, 더보기에는 해당 종류와 새
  스냅샷을 사용한다. 분석 입력 변경 시 진행 중인 필터 조회도 취소한다.

얼굴 부위 오버레이와 자동 얼굴 확대는 이번 패치에 포함하지 않았다.
기존의 계정 귀속, QR 헤어 결과, 실제 메일 발송 등의 백엔드 과제도 유지된다.

## 적용

```powershell
cd C:\Users\USER\Desktop\BOA-git
git apply --check "$env:USERPROFILE\Downloads\boa-frontend-v5.patch"
if ($LASTEXITCODE -eq 0) {
    git apply "$env:USERPROFILE\Downloads\boa-frontend-v5.patch"
}
```

검사가 실패하면 적용하지 말고 현재 패치 버전을 확인한다. 적용 성공 후:

```powershell
cd frontend
pnpm build
pnpm lint
node scripts/test-api-client.mjs
pnpm dev
```

기존 백엔드도 실행 중이어야 한다. 이번 패치에 DB 작업은 없다.
로컬에서 사진 찍기를 눌러 권한을 허용하고 촬영·취소를 확인한다.

## 검증

- TypeScript·Vite 빌드, oxlint, 기존 API 클라이언트 16개 검사 통과.
- 브라우저 39개 확인: 큰 사진, 확대·위치·전체 보기, 결과 유지,
  원본 바이트 전송, 처음 전체 추천, 종류별 재조회, 점수 재사용,
  더보기의 종류·페이지 정보, 실패 복구, 연속 선택·입력 변경 취소,
  촬영·카메라 전환·취소·권한 거부·늦은 허용·화면 이동의 스트림 정리,
  JPEG 전송, 이미지 URL 정리, 모바일·데스크톱 넘침 및 JS 오류.
- API는 테스트 응답, 카메라는 브라우저의 테스트 영상 스트림을 사용했다.
  사용자 PC의 실제 웹캠·권한 설정과 실제 CV 분석은 별도 확인 대상이다.
- 레이아웃 검증용 한글 폰트는 테스트 브라우저에만 적용했다.
  애플리케이션에 외부 폰트나 얼굴 인식 모델을 추가하지 않았다.

팀 머지와 원격 푸시는 수행하지 않았다.
