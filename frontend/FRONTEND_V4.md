# BOA 프런트엔드 v4 — 입력과 결과 확인 개선

기준: v3 (`12a7400`). v3가 적용된 작업 폴더에 추가하는 패치다.
변경 범위는 `frontend/`뿐이다. 백엔드, DB, 마이그레이션, API 요청 계약,
추천 규칙 및 패키지 의존성은 변경하지 않았다.

## 변경 내용

- 화장품 추천이 0개이면 서버 응답을 기준으로 개선 대상 없음, 매칭 보류,
  제품 데이터 없음, 조건에 맞는 제품 없음으로 나눠 안내한다.
  서버의 원래 사유와 미측정 수분 안내를 함께 보여 준다.
- 피부·헤어 결과로 바로 이동하고 입력 조건으로 돌아가는 버튼을 추가했다.
  버튼을 누르면 해당 제목으로 키보드 초점도 이동한다.
  분석 완료 시 사용자가 보고 있는 다른 화면의 초점을 자동으로 가져오지 않는다.
- 결과 조회에 원래 토큰과 BOA 공유 주소를 모두 입력할 수 있다.
  주소에서 토큰만 추출해 기존 API로 전달하며 해당 주소로 이동하지 않는다.
  토큰이 없거나 중복된 링크, 잘못된 형식은 요청 전에 안내한다.
- 헤어 사진이 2장이면 바로 안내하고 제출을 막는다.
  선택한 스타일 구분에 카탈로그가 없을 때도 안내하고 제출을 막는다.
- 최근 결과가 새로고침 후 자동 복원되지 않는다는 안내를 추가했다.

## 적용

다운로드한 파일명이 `boa-frontend-v4.patch`인지 확인한다.
다음 명령은 v3가 적용된 로컬 BOA 저장소에서 실행한다.
검사가 실패하면 적용하지 않고 현재 버전을 확인한다.

```powershell
cd C:\Users\USER\Desktop\BOA-git
git apply --check "$env:USERPROFILE\Downloads\boa-frontend-v4.patch"
if ($LASTEXITCODE -eq 0) {
    git apply "$env:USERPROFILE\Downloads\boa-frontend-v4.patch"
}
```

적용 성공 후 확인:

```powershell
cd frontend
pnpm build
pnpm lint
node scripts/test-api-client.mjs
pnpm dev
```

## 검증 범위

- TypeScript·Vite 빌드, oxlint, 기존 API 클라이언트 16개 검사 통과.
- 브라우저 28개 확인: 4가지 빈 추천 안내, 점수 배열·photo_v1 전달 유지,
  추천 재조회 시 사진 분석 재사용, 피부·헤어 결과 이동과 초점,
  토큰·공유 주소 조회, 잘못된 주소의 요청 차단, 헤어 사진 2장 및
  해당 스타일 카탈로그 없음 안내, 모바일·데스크톱 넘침, JS 오류 확인.
- 브라우저 검증은 테스트용 API 응답으로 진행했다.
  실제 얼굴 인식, 인증 쿠키, 이메일 발송, 운영 DB 연결 검증을 의미하지 않는다.
- 한글 레이아웃 확인용 폰트는 테스트 브라우저에만 적용했다.
  앱의 폰트 의존성과 배포 파일은 변경하지 않았다.

기존의 분석 결과 사용자 연결, QR 헤어 결과, 로그인 자동 갱신 및 이메일
실제 발송은 이번 패치에 포함하지 않는다. 팀 머지와 원격 푸시도 수행하지 않는다.
