# BOA 태블릿 화면 v9

- 홍보 문구와 장식용 인물 사진 제거. 기능 이름과 조작 안내 중심으로 변경.
- 홈, 시작·계정, 피부·화장품, 얼굴형·헤어, 이번 분석 결과, 키오스크, AI Studio 7개 메뉴를 모두 표시.
- 홈에 6개 기능 진입 버튼 표시. AI Studio는 준비 중 표시 및 기존 안내 화면 유지.
- 가로 태블릿 3열, 세로 태블릿 2열, 휴대폰 1열 기능 버튼.
- 사이드 메뉴 64px, 일반 버튼·입력 48px 이상, 주요 분석 버튼 56px.
- 기존 API, 인증, 세션, 분석, 추천 로직 유지. 백엔드 및 DB 수정 없음.

검증: 빌드, 린트, API 클라이언트 검사 16개. 테스트 응답으로 1024×768·768×1024·390×844 화면과 7개 메뉴, 사진 입력·추천·종류 필터를 검토합니다. 실제 태블릿 카메라·실제 백엔드는 로컬에서 확인이 필요합니다.

태블릿용 화면 배치 변경입니다. 운영체제 키오스크 잠금이나 자동 세션 종료 등의 새로운 기능은 포함하지 않습니다.
