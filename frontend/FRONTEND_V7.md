# BOA 프론트엔드 화면 정리 v7

기준: main b3c10c9e44f7448c4c9ae36a1614bbcac574fc05 (2026-10-19 확인).

## 변경 범위
- 피부·화장품 화면의 큰 사진 입력 영역과 촬영 안내, 분석 시작 영역 정리.
- 사진이 없을 때 분석 버튼 비활성화. 연동 테스트 도구를 입력 화면 아래로 이동.
- 제품 이미지를 위에 둔 카드: PC 3열, 중간 화면 2열, 모바일 1열.
- 피부 지표, 종류 필터, 제품, 상세 근거의 읽는 순서 정리.
- 미측정 지표 이름을 한글로 표시.
- 공용 사진 업로드 안내와 제품 카드 변경은 헤어 입력·이번 분석 결과에도 반영됩니다.

백엔드, DB, API 형식, 추천 점수·정렬 로직, 인증 로직은 변경하지 않습니다.
사진 확대·이동은 기존처럼 미리보기 전용이고 분석에는 원본을 전송합니다.
새 런타임 패키지나 외부 폰트 의존성은 추가하지 않습니다.

## 검증
- pnpm build, pnpm lint, API 클라이언트 검사 16개 통과.
- 브라우저에서 테스트 API 응답으로 사진 업로드, 추천 카드 표시, 종류 필터, 오류 시 결과 유지, 일상 관리 응답, 빈 결과, 모바일 가로 넘침 및 런타임 오류 확인.
- PC 및 모바일 화면 캡처를 검토했습니다. 실제 백엔드 통합 테스트는 로컬에서 확인해야 합니다.

## 적용
저장소 루트에 패치를 놓고 PowerShell에서 실행합니다.

```powershell
git apply --check .\boa-frontend-visual-v7.patch
# 위 검사에 오류가 없을 때:
git apply .\boa-frontend-visual-v7.patch
cd frontend
pnpm build
pnpm lint
node scripts/test-api-client.mjs
pnpm dev
```

적용 검사에서 충돌이 나오면 강제로 덮어쓰지 말고 오류 내용을 공유해 주세요.
원격 push나 PR merge는 이 패치에 포함되지 않습니다.
