# BOA 태블릿 UI v10

v9의 홈, 사이드 메뉴 및 모든 기능 진입점을 유지합니다.

- 사진 선택 후 분석 시작 버튼을 화면 하단에 고정합니다. 사진이 없거나 추천 결과가 표시된 상태에서는 일반 배치입니다. 처리 중 중복 제출을 막습니다.
- 추가 조건 입력은 그대로 유지하고 반복되는 분석 항목 설명을 제거했습니다.
- 추천 결과는 피부 지표, 종류 필터, 제품 순서로 표시합니다. 긴 추천 기준은 제품 목록 다음에 펼쳐볼 수 있습니다.
- 제품명과 추천 이유의 글자를 키우고 태블릿 제품 목록은 2열로 표시합니다. 지표 간 공통 근거는 접어서 표시합니다.

백엔드, API 형식, 추천 점수/정렬, 인증/세션 로직은 수정하지 않았습니다.

검증: build, lint, API client 16 checks. 테스트 API 응답을 연결한 브라우저에서 7개 메뉴, 사진 업로드, 추천과 필터, 3개 화면 크기, 선택 후 고정 버튼의 화면 내 위치, 결과 표시 후 고정 해제를 확인했습니다. 실제 태블릿의 카메라와 가상 키보드는 로컬 기기에서 확인해야 합니다.
